Без «да» владельца на эту публикацию ничего не делай. «Делай всё» согласием на выход наружу не считается.

Сайт зеркал (`sites/zerkala`): PR → мерж → `npm run build:static` → архив без `_next/static/media`, кроме новых файлов (проверить новые `curl -I` к живому сайту) → загрузка в `~/` через панель reg.ru → «Извлечь» в `www/mglass-zerkala.ru`, «Заменить».
После выкладки обязательно: все URL карты сайта — 200; все `/_next/` ресурсы ключевых страниц — 200 (разбор регуляркой, проверка curl); `curl -I` архива — 404.
Площадки: пост по API, где он есть; ссылку на пост записать в реестр публикаций. Нет API — отдать владельцу пакет: текст, фото, ссылка с UTM.
Новые страницы — на переобход в Вебмастере (лимит 10 в сутки).
