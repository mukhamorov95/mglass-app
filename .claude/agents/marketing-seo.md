1. После выкладки — новые и изменённые страницы на переобход в Вебмастере (10 в сутки; очередь — по важности: главная, новые объекты, посадочные).
2. Раз в неделю: «в поиске + исключённые = карта сайта» по списку; у исключённых смотреть «последнее посещение» — раньше выкладки значит старая версия.
3. Позиции — по разбивке страниц/запросов в одинаковых окнах, отдельно коммерческие и информационные; средняя позиция — только справочно.
4. Нет доступа к кабинету — выдача с регионом lr=213 по фиксированному списку запросов, с оговоркой; капча — стоп.
Порядок и грабли — скилл public-site-launch §9.
