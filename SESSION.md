## ВАЖНО про #167 (архитектура цены)
Ручной `waste_percent` НЕ влияет на цену клиента: цена B2B = `salePerM2 × нетто` из прайса (b2bCalculator.ts:234). Процент идёт только в `costMaterial → себестоимость → маржа/прибыль`. Значит «включить авторасход в цену» = сделать честную СЕБЕСТОИМОСТЬ и МАРЖУ (клиент платит по прайсу без изменений). Cutover: заменить ручной % на авто по материалу в `calcItem`, отключить ручной ввод % в калькуляторе и /admin/glass-prices (лофт оставить — он тоже читает waste_pct отдельно).

## Что сделано (эта сессия — экономика цеха)
- **#163 Аудит оптимизатора раскроя** — прогнан на 160 июльских заказах (`scripts/_audit_optimizer.ts`). Инварианты держатся: ноль наложений, потерь деталей, выходов за лист, искажений габаритов при повороте. Вывод: **алгоритм корректен**; рычаг экономии — не в нём (глубокий поиск даёт −2.6% листов), а в **партионности**: раскрой по каждому заказу 245 листов → по дню 214 → месяцем 151 (−38%). Возможность батчить уже есть в `/b2b-cutting` (выбор нескольких заказов).
- **Разбор «отхода»**: наивное «раскрой по заказу = 128% сверх нетто» — фантом. 96% этого «отхода» — крупные остатки на стеллаж, безвозвратная потеря реза всего **5%** (медиана по заказу 2.2%, 90-й перцентиль 8.5%). Ручные 18–45% — это в основном оценка невозвратного остатка, а не геометрия.
- **#164 `lib/materialUsage.ts`** — автоматический расход поверх оптимизатора: нетто + потеря реза + остаток×(1−reuseRate). Границы: reuseRate=1 → +потеря реза; reuseRate=0 → целые листы. Движок готов и показан на экране; ЗАМЕНА ручного % в цене — отдельный переключатель #167 (меняет цены → решение владельца).
- **#166 `lib/laborModel.ts`** — ставка труда = оклад ÷ объём периода (operating leverage). Июль: резка 206 ₽/м², сверловка 3061 ₽/дет (объём мал), кромка 36.5 ₽/м, упаковка 167 ₽/м². **Резки и сверловки в себестоимости не было вообще** — сидели в марже.
- **#165 `/cfo/order-economics`** — экран «Честная экономика заказа»: маржа по системе vs честная, материал ручной vs раскрой, труд по живым ставкам с пометкой «не в себест.», таблица заказов от худшей честной маржи. Ссылка добавлена в `/cfo`.
- **Итог июля (проверено `scripts/_verify_economics.ts`):** маржа система **46.8% → честная 32.4%** (−14.4 п.п., спрятано 532k/мес). Материал при 70% реюза занижен на 197k. Труд: заложено 551k → честно 887k (разница = резка 160k + сверловка 150k).
- Тесты: `__tests__/materialUsage.test.ts` (10) + весь набор 205 — зелёные. tsc чисто по новым файлам, `next build ✓ 33.4s`, lint 0 ошибок.
