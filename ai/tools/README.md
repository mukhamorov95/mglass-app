# ai/tools/ — Реестр инструментов агентов

Инструменты — это разрешённые операции доступа к данным. Каждый инструмент:
- имеет явный уровень разрешения (`ToolPermission`)
- возвращает типизированный результат
- логирует вызов через `writeAgentLog`
- не изменяет бизнес-данные без уровня `execute` или `admin`

## Файлы

| Файл | Назначение |
|---|---|
| `tool-registry.ts` | Типы и декларативный реестр всех инструментов |

## Уровни разрешений (ToolPermission)

| Уровень | Описание |
|---|---|
| `read_only` | Только чтение. Никаких изменений. |
| `draft` | Создание черновика. Не отправляется и не сохраняется без подтверждения. |
| `suggest` | Предложение действия. Ждёт одобрения. |
| `approve_required` | Требует явного подтверждения Владислава перед выполнением. |
| `execute` | Выполняет действие. Доступно только агентам с явным разрешением. |
| `admin` | Системные операции. Только для системного уровня. |

## Правила добавления новых инструментов

1. Добавить описание в `tool-registry.ts` с типом `ToolDefinition`
2. Указать `permission` — минимально необходимый
3. Указать `allowedAgents` — только те агенты, которым это действительно нужно
4. Реализовать в `lib/` или `app/api/` отдельным модулем
5. Добавить логирование через `writeAgentLog` до и после вызова
