а не двадцать пять: лишние не просто не используются, они прячут нужный.

## Что нужно сделать

**Шаг 1 — инвентаризация.** По каждому из 25: что показывает, откуда данные, есть ли на него
входы (ссылки из навигации и других экранов), есть ли следы использования. Вывод по каждому:
`оставить` / `слить с X` / `удалить` / `не трогать — чужой домен`.

**Шаг 2 — прислать список мне.** С обоснованием по каждой строке. Я согласую с владельцем
спорные (`voronezh`, `ideas`, `guide`, `demo`, `scan`) — по ним нужен его ответ, а не наша догадка.
Формулируй конкретные вопросы, а не «что удалить?».

**Шаг 3 — после «принято»** — слияние и один рабочий экран смены.

## Критерии приёмки

- Ни один экран не удалён до моего подтверждения.
- Экран без данных ≠ экран для удаления: сначала проверь, нет ли у него входа (может, он
  полезен, но до него не дойти) — это разные диагнозы и разные решения.
- Удаление — только после проверки, что на экран нет ссылок из других контуров
  (менеджерского, админского). Чужие ссылки ломать нельзя.
- Рабочий экран проверяется вопросом «станет ли смена проще», а не «стало ли меньше файлов».
