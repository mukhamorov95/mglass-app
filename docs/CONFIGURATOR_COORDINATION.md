# Координация: конфигуратор душевых (2 параллельные сессии)

Две сессии Claude работают над одним продуктом и **должны действовать согласованно**.
Этот файл — единый источник правды: кто за что отвечает, где граница, и лог «кто что сделал».
**Перед работой — прочитать этот файл. После значимого шага — дописать строку в лог.**

## Разделение зон

### 🖥️ Сессия «Сайт + 3D» (ветка feat/shower-3d-configurator)
Клиентский сайт с 3D-моделью изделия — наш ноу-хау, отличие на рынке.
- Сайт-хост 3D-модели, embed-виджет, страница на Tilda
- 3D-визуализация: three.js / @react-three/fiber / drei — сцена, материалы, свет, тени
- Топология/геометрия изделия: `lib/configurator/arrangement.ts`, `components/configurator/scene/assembly.ts`, `buildFromModel`
- UX клиента: выбор модели/стекла/цвета/фурнитуры, применение выбора к 3D
- Инструменты логиста для наполнения себестоимости (справочник, пикер, избранное, сравнение)
- **Производит** `Quantities` из 3D-модели (`computeQuantities`)

### 💰 Сессия «Прайсовая система» (shower-pricing-system)
Математика: как складывается цена душевой.
- Финмодель: `Цена = Себест / (1 − маржа% − налог%)`, налог 12%, маржа из настроек
- `computePrice`, `calcFinancialModel`, `lib/pricing/*`
- Хлысты (pickStock/barsCost), себестоимость по BOM, монтаж/доставка/подъём
- Наценки, тиры (budget/standard/premium), детализация цены
- **Потребляет** `Quantities` + `UnitPrices` → выдаёт `PriceResult`

## 🔗 Контракт между сессиями — тип `Quantities` (lib/configurator/pricing.ts:15)
Это шов. Сайт/3D гарантирует корректный `Quantities` из модели; Прайс гарантирует корректный
`PriceResult` из `Quantities`+`UnitPrices`.
```
computeQuantities(assembly, thickness) → Quantities   // владелец: Сайт+3D (геометрия)
computePrice(quantities, unitPrices, opts) → PriceResult // владелец: Прайс (математика)
```
**Правило:** менять поля `Quantities`, `UnitPrices`, `PriceResult`, роли (`rolesFrom`) или
ключи геометрии фурнитуры — только с записью в лог ниже и, по возможности, пингом второй сессии
(SendMessage). Кто меняет форму контракта — предупреждает.
