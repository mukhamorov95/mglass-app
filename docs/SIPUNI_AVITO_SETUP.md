# Звонки с Авито → менеджерам, а не владельцу (настройка SIPUNI)

Цель: звонок с Авито звонит группе менеджеров; владельцу — только если никто
не взял. Всё делается в кабинетах SIPUNI и Авито, без кода.

## Шаг 1. Группа менеджеров в SIPUNI
1. Кабинет SIPUNI → **Настройки → Сотрудники**: убедиться, что у Яны/Алины/Семёна
   заведены внутренние номера (или мобильные для переадресации).
2. **Настройки → Отделы (группы)** → «Создать отдел» → название «Продажи Авито»,
   добавить менеджеров.
3. Тип обзвона в отделе:
   - **«Все сразу»** — звонит всем, берёт первый освободившийся (рекомендую для старта);
   - «По очереди» — если хотите равномерное распределение.

## Шаг 2. Сценарий входящего звонка
1. **Настройки → Схемы вызовов (IVR)** → создать схему «Авито»:
   - Входящий звонок → узел «Отдел: Продажи Авито», таймаут **30 секунд**;
   - Если никто не ответил → узел «Сотрудник: Владислав» (ваш номер);
   - Если и там нет ответа → голосовая почта / завершение.
2. Привязать схему к номеру, на который будет приходить Авито (шаг 3).

## Шаг 3. Переадресация в Авито
1. Кабинет Авито → **Управление → Телефония / Номера** (раздел подключения звонков).
2. Указать номером приёма звонков ваш **многоканальный номер SIPUNI**
   (тот, к которому привязана схема «Авито»).
3. Подменный номер Авито оставить включённым — статистика звонков сохранится.

## Шаг 4. Спасение пропущенных (после подключения ключей Авито)
- SIPUNI → **Настройки → API/Вебхуки**: включить уведомление о пропущенных
  на `https://mglass-app.vercel.app/api/sipuni/missed` (роут добавим, когда
  дойдём до этого шага) — клиенту автоматически уйдёт сообщение
  «не дозвонились — напишите, посчитаем за 2 минуты», и диалог подхватит AI-менеджер.

## Проверка
Позвонить на номер с постороннего телефона: должны зазвонить менеджеры,
через 30 сек — владелец. В отчётах SIPUNI звонок виден по схеме «Авито».
