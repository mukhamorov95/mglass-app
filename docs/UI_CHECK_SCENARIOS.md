# Сквозная проверка кабинета менеджера

> Зачем. Правки в экранах за логином принимались на слово: «типы сходятся, сборка
> зелёная». Так прошла дыра, из-за которой расчёт №134 сохранился без клиента —
> проверка жила в браузере, а браузер был старше выката. Ниже сценарии, которые
> ловят такие вещи до выката, а не через три дня после.

## Как запускать

Пароли вводит владелец, не Claude. Порядок:

1. Владелец открывает браузер Playwright и **входит сам** — пароль набирает он.
2. Дальше сессия живёт в этом браузере, и Claude прогоняет сценарии в ней:
   кликает, заполняет, читает результат.
3. После прогона Claude показывает, что получилось: снимки экрана и записи из базы.

Проверять на dev (`npx next dev -p 3005`) до мержа, на проде — после.

## Сценарии

### С1. Расчёт без клиента не сохраняется
1. `/calculator/build` → выбрать М2 → задать габариты → дождаться цены.
2. Не заполнять имя и телефон. Нажать «Сохранить → КП».
3. **Ждём:** кнопка неактивна, под ней подсказка про имя и телефон.
4. **В базе:** новых строк в `calculations` нет.

### С2. Расчёт с клиентом заводит сделку
1. То же, но вписать имя и телефон (10+ цифр).
2. Сохранить.
3. **Ждём:** переход на `/kp`, в базе новая строка `calculations` с `deal_id`,
   и новая строка в `deals` с этим телефоном.

### С3. Старая вкладка не обходит правило
1. Открыть `/calculator/build`, посчитать, **не сохранять**.
2. В другой вкладке — что угодно; сервер при этом уже с новым кодом.
3. Вернуться в первую вкладку и сохранить без клиента.
4. **Ждём:** сервер отвечает 422 с текстом про имя клиента. Запись не создана.
   Это то, что не ловилось, пока правило жило на экране.

### С4. Расчёты без клиента видны и привязываются
1. `/calculator/quick` → посчитать → сохранить без клиента (так можно).
2. Открыть `/my-day`.
3. **Ждём:** блок «Расчёты без клиента», в нём этот расчёт.
4. Вписать имя и телефон → «Завести сделку».
5. **Ждём:** расчёт исчез из блока, в `deals` новая сделка, у расчёта `deal_id`.

### С5. Фурнитура считается по прайсу визуализатора
1. `/calculator/build` → М11 → 900×2000 → хром.
2. **Ждём:** себестоимость фурнитуры ≈ 16 700 ₽, а не 8 400 ₽ (старый флэт).
3. Выбрать М3 (модель вне ряда конфигуратора) на `/calculator/shower`.
4. **Ждём:** красный блок «Цена фурнитуры не считается», а не подставленный флэт.

### С6. Менеджер не видит чужого
1. Войти менеджером без `can_view_all_deals`.
2. `/deals`, `/my-day`, `/calculations`.
3. **Ждём:** только свои сделки и расчёты. Чужой расчёт по прямой ссылке — отказ.

## Что проверять в базе после прогона

```sql
-- появились ли записи и куда легли
select id, created_at, product_type, client_name, deal_id, final_price
from calculations order by created_at desc limit 5;

select id, created_at, client_name, phone, address from deals order by created_at desc limit 5;
```
