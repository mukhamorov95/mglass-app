Картинки — фото из обложек объявлений (сгенерированы GPT 05.10), без заголовков, цен и плашек:
текст на картинке в рекламе — не больше 20 % площади, плашки и «от … ₽» снижают CTR и рискуют
модерацией. Четыре пропорции нативного формата: 4:5 600×750, 4:3 720×540, 1:1 472×472,
8:3 1372×512 (JPEG < 200 КБ, лимит 2 МБ). Логотип не ставим.
