## 1. Зеркала с подсветкой для салона красоты
Папка `1-salon-krasoty` (2 фото).

Изготовили зеркала для рабочих мест студии красоты: зеркала на потолочном подвесе и

сборка с подсветкой на нашем производстве в Мытищах.

## 2. Зеркальное панно с фацетом
Папка `2-panno-facet` (1 фото).

Панно из зеркальных элементов по эскизу заказчика: фигурная резка, фацет по кромке, раскладка
со световыми вставками. Каждый элемент режем и обрабатываем на своём оборудовании.

## 3. Зеркала нестандартной формы
Папка `3-nestandartnaya-forma` (3 фото).

Фигурные зеркала по шаблону: «капля», двойная арка, асимметричная форма. Режем по векторному
макету или картонному шаблону, полируем кромку, ставим подсветку и бесконтактный выключатель.
Делаем по одной детали и партиями для мебельщиков и дизайнеров.

## 4. Зеркальные панели в прихожей
Папка `4-prihozhaya` (2 фото).

Зеркальные панели во всю высоту стены и встроенная в шкаф зеркальная стенка. Режем в размер по
замеру, полируем кромку, делаем вырезы под розетки и выключатели.
