# Раскладка B2B-калькулятора: всё под рукой без прокрутки

Просьба владельца (07.10.2026): «структурируй, где-то сжать, ужать… чтобы доступ ко всему был, чтобы не нужно было листать вниз сильно долго». Условие: «рабочее всё, ничего не меняем». Поэтому меняется только раскладка. Расчёт, сохранение, тексты и права остаются прежними.

## Цель
На экране ноутбука (1568×781) без прокрутки видно:
* кому считаем;
* форму позиции до кнопки «+ Добавить позицию»;
* итог;
* «Сохранить».

Проверяется кадром `/calculator/b2b` в сессии владельца.

## Этапы

### 1. Раскладка формы и итога — СДЕЛАНО (PR этого этапа)
* `app/calculator/b2b/page.tsx`: шапка заказа, «Детали заказа», «📎 Файл клиента», компактная обработка, итог над списком, справка по цене под списком.
* `app/calculator/b2b/TreatToggle.tsx`: 36 px на широком экране.
* «Расчёт B2B для M-Glass» (`variant='mglass'`): шапки нет, потому что в ней нечего выбирать. Примечание остаётся внизу формы, быстрый расчёт и «Изделия в КП» — под списком, как раньше.
* Риск: менеджеры привыкли к старым местам кнопок. Смягчение: сами кнопки и подписи прежние, сдвинуты только места.

### 2. Меню слева — не делалось, предложение
В группе B2B у каждого пункта повторяется «B2B»: «B2B Калькулятор», «B2B Просчёты», «B2B Заказы». Можно убрать повтор и поставить пункты по ходу работы: заявка → расчёт → просчёт → заказ → счёт. Подписи заодно видны в `/admin/activity` (`PageUsage`), поэтому делать только по слову владельца.

### 3. Окно правки позиции — не делалось
В нём нет отверстий по группам и вырезов: их значения переносятся из позиции, но не правятся. Это функция, а не раскладка, поэтому вне этой просьбы.

## Грабли
* Сетка «Обработки» — две колонки, а не три: при трёх «Криволинейка» вылезает за ячейку (комментарий в коде). Компактность взята высотой, а не колонками.
* У «Сверловки» подпись стоит в строке, но блок остался отдельным: отверстия и вырезы — одна станция, это осознанная группировка.
* `id="b2b-kp"` нужен кнопке «Клиентский расчёт (КП)» — блок КП переехал, id остался.
* На macOS нет `timeout`: `timeout 300 npx tsc` молча не запускает проверку (код 127, пустой вывод).

## Потолок
Таблица позиций — 17 колонок. В правой колонке (≈850 px) она прокручивается вбок при любой раскладке. Сжать её можно только убрав колонки, а это уже решение о данных, не о раскладке.
