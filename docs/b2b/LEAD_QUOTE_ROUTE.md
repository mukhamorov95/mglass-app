# Просчёт без заказчика: Авито и другие входящие

Просьба владельца (07.10.2026). Первый запрос в B2B приходит через Авито: человек пишет размер и спрашивает цену.

## Цель
Ответить ценой за минуту и не заводить клиента до слова «заказываю»:
1. Посчитать в `/calculator/b2b`.
2. Сохранить с отметками «откуда» и «кто».
3. Скопировать готовый текст в чат.
4. Заказчика привязать потом.

Готово, когда сценарий со скриншота владельца проходит без карточки клиента: «480×1835, тонированное графит 4 мм — сколько?» → текст в чат.

## Структура (как сказал владелец)
Две независимые оси, а не одна «розница = Авито»:
* **Откуда пришёл** — `lead_source`. Список тот же, что у клиента (`B2B_SOURCES`, `b2b_clients.crm_source`): Авито, сайт, рекомендация…
* **Кто он** — `customer_kind`: розница или опт. С Авито может прийти и оптовик.
* `lead_contact` — имя из чата для приветствия, пока карточки нет.

Хранится в `notes` заказа, поэтому миграции не нужно. Колонка `b2b_orders.source` занята другим: канал создания (свой или кабинет партнёра).

## Этапы

### 1. Просчёт без заказчика, отметки, текст для чата — СДЕЛАНО (PR этого этапа)
* `lib/b2b/leadQuote.ts`:
  * чтение и проверка отметок;
  * блокировка сохранения без «откуда» и «кто»;
  * текст ответа: суммы строк как в калькуляторе, по сохранённому — как в счёте.
* Калькулятор:
  * блок «Откуда пришёл / Кто», имя из чата;
  * «Сохранить без заказчика»;
  * «📋 Текст для Авито» (или «Текст клиенту», если источник другой);
  * «+ Новый клиент» заполняется именем и источником;
  * если прайс или скидка клиента меняют уже названную цену — жёлтое предупреждение.
* «Просчёты»:
  * метки «Авито · розница · без заказчика»;
  * «＋ Заказчик →» ведёт в калькулятор;
  * «📋 Текст для Авито» в меню строки.
* Сервер:
  * `quote-notes` принимает три новых ключа только с известными значениями;
  * `b2b-quotes/[id]/notes` не запускает просчёт без клиента.
* Риск: цена без клиента идёт по общему прайсу. Отдельной розничной наценки нет, это решение владельца (см. «Открыто»).

### 1б. Клиент — поиском в обоих алфавитах — СДЕЛАНО (просьба владельца 07.10, 17:20)
* Вместо длинного списка — поле с поиском (`components/ClientPicker.tsx`, `lib/search/translitMatch.ts`). Обе строки сводятся к одному «звуковому» ключу на латинице, поэтому «шо» находит ShowerGlass, «гласс» — все шесть «гласс», «мр» — MR GLASS.
* Ищется и по юрлицам клиента: «литвин» находит СпецМонтаж, под названием подписано, по какому юрлицу нашли. Ещё ищется по контакту, ИНН и телефону. Клавиши ↑↓ и Enter.
* Попутно найдено: калькулятор грузил клиентов без `crm_source`, и подтягивание источника из карточки (этап 1) молча не работало. Теперь грузит.

### 2. Розница/опт у карточки клиента — ждёт решения
Сейчас «кто» стоит на просчёте. Чтобы клиент, привязанный из Авито, оставался розничным во всех отчётах, нужна колонка `b2b_clients.customer_kind`. Её добавляет SQL владельца.

### 3. Конверсия входящих — после недели данных
В `/b2b-crm/report` для каждого источника считать:
* сколько просчётов;
* сколько из них стало заказами;
* сумму.

Без этого не видно, окупается ли Авито.

### 4. Связь с заявками GLASMEN
Сюда относятся `b2b_inquiries` (0 строк на 07.10) и А4 маршрута `docs/avito-b2b/AVITO_B2B_ROUTE.md`. Когда чаты Авито пойдут в приложение, у просчёта появится ссылка на чат.

## Открыто
* **Розничная цена.** Розница сейчас считается по тому же прайсу, что опт (минимальная цена позиции работает: 3 000 ₽ в примере). Нужна ли наценка для розницы — решение владельца.
* **Текст ответа.** Строки «Забрать можно в Мытищах, доставка — по договорённости» и «напишите, оформим заказ» не содержат условий оплаты. Если они есть, их стоит добавить одной строкой.

## Грабли
* Объект, собранный в render и переданный в функцию, ломает React Compiler: «memoization could not be preserved» на соседних `useMemo`. Отметки собраны в `useMemo`.
* У 1 657 заказов до 06.07 нет `client_id`, и все они запущены. Запрет запуска без клиента касается только незапущенных.

## Потолок
Текст копируется руками: приложение в Авито не пишет. Отправка из приложения требует Messenger API — это тариф «Расширенная», решение 1 маршрута Авито, и отдельное «да» владельца на каждую отправку.
