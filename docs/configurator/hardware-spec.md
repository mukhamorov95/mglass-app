# Спецификация фурнитуры душевых — источник правды для 3D-конфигуратора

> Этот файл — **единый источник правды** по тому, как выглядит и из чего собрана
> каждая модель. 3D-билдер (`components/configurator/scene/assembly.ts`) должен
> строить строго по нему. Владелец правит этот файл (или диктует правки) —
> Claude приводит 3D в соответствие. Так детали не теряются между сессиями.

## Как передавать технические параметры (для владельца)

Ранжировано по точности:

1. **Аннотированный эскиз / фото с размерами.** Как карандашный эскиз раздвижки —
   идеально. Максимально полезно, если указать: размеры в мм, какой край куда
   крепится, и вид (спереди / сверху / сбоку). Геометрию так передавать лучше всего.
2. **Чертёж производителя.** Каталог «Комплектации перегородок.pdf» уже в проекте
   (`public/configurator/hardware/rd-001-*.jpg`). Пришлёшь сечение профиля/узла с
   размерами — впишу точь-в-точь.
3. **Короткая правка словами по словарю компонентов** (ниже). Пример:
   «M10: нижний профиль на поддон, заглушка в стыке двери» — этого достаточно.
4. **Разметка по нумерованному рендеру.** Даю лист с номерами узлов — пишешь
   «узел 3 неправильно, должно быть …».

**Шаблон правки:** `<модель или "все"> · <узел> · <что не так> → <как должно быть> [размеры/угол]`

## Правила геометрии (общие)

- Единицы в билдере — метры (мм × 0.001). Сборка поднимается на поддон группой
  `y = trayH`, поэтому координаты узлов — **локальные, без TRAY_H**.
- **Нижний П-профиль — на поддоне**, у самого низа стекла (стекло стоит В профиле).
  `bottomY = 0.0125/2`. ✅ (исправлено — раньше всплывал на ~60 мм).
- **Штанга раздвижной** — с отступом ~60 мм от верха до оси (`TUBE_DROP`). Над
  штангой есть стекло. ✅
- Раздвижная створка вынесена вперёд на `SLIDE_GAP` (передний рельс).
- Распашная дверь открывается **наружу** вокруг петлевой кромки; петля на стекле.
