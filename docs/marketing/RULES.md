документу. Каждое правило — с источником и датой проверки. **Факт** — прочитано в первоисточнике;
**сообщается** — во вторичном источнике (СМИ, юристы), формальный акт не найден; **не проверено** —
так и написано, с тем, что пробовали.

### 2.1. Свой пост о работе — реклама или нет

**Факт.** Письмо ФАС АК/56172/16 от 16.08.2016: не является рекламой информация о товарах
«на официальном сайте производителя или продавца… в социальных сетях… если указанные сведения
предназначены для информирования посетителей… об ассортименте, правилах пользования, стоимости,
условиях предоставления скидок». Если конкретный товар **выделяется** среди других, информация
может стать рекламой.

**Факт (ТАСС, 27.10.2022, позиция ФАС):** посты в публичных Telegram-каналах подпадают под закон
о рекламе и требуют маркировки, если это реклама.

**Наше правило:**
- пост «вот объект, что сделали, размеры и цена» в **своём** сообществе — информация, без ERID;
- нет призывов «закажи сейчас», «скидка до пятницы», «лучшие в Москве» — это признаки рекламы;
- всё, за что платим площадке или блогеру (продвижение записи, посев, таргет) — **реклама**:
  ERID через оператора рекламных данных (ОРД) до публикации, пометка «Реклама» и рекламодатель.
  Оператора выбираем, когда дойдём до первой платной рекламы.

### 2.2. Telegram и YouTube — спорная зона

**Сообщается** (pravo.ru, 06.03.2026; не первоисточник ФАС):
- ФАС 25.02 и 26.02.2026 возбудила дела по ч. 10.7 о рекламе на YouTube и в Telegram;
- ФАС заявила, что запрет касается WhatsApp, Instagram, Facebook, VPN; РКН назвал разъяснения
  «исчерпывающими»;
- юристы спорят: Telegram в реестр ограниченных ресурсов не внесён;
- СМИ пишут о «послаблении» до 31.12.2026 — официального текста **не нашли**.

Наша база знаний (05.10) называла «вне закона с 01.01.2027» — по тексту ч. 10.7 норма действует
с 01.09.2025; дата 2027 — из пересказов о послаблении, первоисточника нет.

**Наше правило:** в Telegram — только информационные посты о работах (§2.1), никакой покупной
рекламы, никаких посевов в чужих каналах. YouTube — не начинаем.

## 4. Площадки

### 4.1. ВКонтакте

**Факт** (dev.vk.com, проверено 19.11.2026):
- метод `wall.post` работает только с ключом пользователя из Standalone-приложения через
  Implicit Flow;
- право `wall` «выдаётся в исключительных случаях через запрос в поддержку по электронной почте
  devsupport@corp.vk.com»;
- `stats.getPostReach` (охват записи) — ключ пользователя.

**Что делаем:** до получения права — публикует человек вручную или отложенной записью в самой VK;
статистику записи снимаем ключом пользователя (владелец даёт его сам, §6). Запрос права `wall` —
письмо в поддержку VK от имени компании, **отдельное «да» владельца**.

**Не проверено:** правила сообщества VK о ссылках и частоте постов (не читали полный текст).

### 4.2. Telegram-канал

**Факт** (core.telegram.org/bots/api): бот-администратор канала публикует (`sendMessage`,
`sendPhoto`, `sendMediaGroup`); методов просмотров постов у Bot API нет.

**Что делаем:** публикация — ботом после «да» владельца в боте. Просмотры — либо MTProto-клиент
(вход под аккаунтом владельца, отдельное решение), либо внешний сервис статистики каналов
(Telemetr/TGStat — не проверяли условия). Переходы на сайт — UTM в Метрике, без API Telegram.

### 4.3. Дзен

**Не найдено:** официального публичного API публикации (поиск по документации Дзена и разделу
для авторов, 19.11). В редакторе есть отложенная публикация.
**Сообщается:** лимит 15 публикаций в сутки с 16.02.2026 (вторичный источник).

**Что делаем:** пакет «скопировать и вставить» в дашборде, публикует человек; ссылка на пост
вносится в реестр руками.

### 4.4. Яндекс Бизнес и 2ГИС

**Не найдено:** API публикации постов в Яндекс Бизнесе. 2ГИС — не проверяли.
**Что делаем:** фото работ и записи — вручную в кабинетах; правило про товарный запрос и рубрики
карточки — `public-site-launch` §4а.

### 4.5. Авито

**Факт:** API — developers.avito.ru, доступ по подписке с API (у нас 14–20.10 уже был случай
отключения API при смене тарифа — память `avito-messenger-api-tariff`).
**Не проверено:** правило Авито о ссылках на сайт в тексте объявления (поиск по support.avito.ru
пуст). До проверки — **ссылок на сайты и мессенджеры в объявлениях не ставим**, телефон только
через Авито.

### 4.6. Instagram, Facebook, WhatsApp

Реклама запрещена ч. 10.7 (Meta — экстремистская организация). Не ведём, трафик не покупаем,
в своих текстах на эти площадки не зовём.

## 5. Как модератор проверяет публикацию

Перед кнопкой «утвердить» у каждой публикации в дашборде — отметки:

1. Нет персональных данных и адреса (§3).
2. Изделие на фото совпадает с исходным кадром и чертежом.
3. Каждая цена — из КП объекта.
4. Нет призывов и превосходных степеней; либо это реклама с ERID (§2.1).
5. Площадка не из запрещённых (§1); для Telegram — только информационный пост.
6. Текст — пересказ, а не копия статьи сайта; статья на сайте уже вышла.
7. Ссылка с UTM.

Утверждает владелец, каждую публикацию отдельно (решение 19.11).
