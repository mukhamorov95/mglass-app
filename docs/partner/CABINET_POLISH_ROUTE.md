## Этапы

- **П1. Калькулятор: М1/Серебро по умолчанию, без рифлёных у клиента — СДЕЛАНО (#1122)** — `lib/glass/clientMaterials.ts`
  (тест `__tests__/glass/clientMaterials.test.ts`); кабинет, прилавок, `/calculator/b2b`;
  сервер кабинета отказывает рифлёному словами. Риск: старый заказ с рифлёным в «Повторить» —
  отказ с текстом «считает менеджер».
- **П2. Уведомления без лавины — СДЕЛАНО** — событие старше 3 дней на момент обнаружения пишется
  прочитанным, датой события, без письма (`lib/partnerNotify.ts`, `NEWS_DAYS`). 147 записей Шовер Гласс
  от 24.11 14:42 передатированы SQL-ом по времени запуска/отгрузки (все уже были прочитаны).
- **П3. «Ждут вашего действия» без шума — СДЕЛАНО** — `drawingAsksPartner()` (заявка из кабинета,
  не запущена) в Табло и карточке; `shipsByOurRoute()` убирает «способ получения»; ответ на
  согласование больше не обещает «запускаем», если заказ уже в работе; «готов к выдаче» → «готов и упакован».
- **П4. «Ваш менеджер» — СДЕЛАНО ЧАСТИЧНО** — блок на Табло и в Профиле (`lib/partner/manager.ts`,
  `/api/partner/manager`); колонка `users.work_phone`. Осталось: рабочий телефон Нуржана (даёт владелец),
  Telegram появится, когда Нуржан привяжет бота.
- **П5. Номера, суммы, период** — одна функция номера и суммы; подпись периода на Табло.
- **П6. Тексты — СДЕЛАНО** — «Как пользоваться» по текущему кабинету (счёт после проверки, Отгрузки,
  акт сверки, Команда, Гарантия), подзаголовок профиля без прилавка у не-точек, «Сменить пароль» — блок в Профиле.
- **П7. Телефон** — нижняя панель с подписями, кнопки не обрезаются, «₽» не переносится.
- **П8. Документы** — поиск, группировка по месяцам, честное «УПД».
- **П9. Каталог только точкам; Табло** — полоски и график с числами.
