## Цель

Отдельный сайт только про зеркала на своём домене, который Яндекс индексирует как
тематический ресурс, а посетитель с него оставляет заявку, и она попадает в CRM.

**Чем меряем готовность:**
1. Каждая посадочная из карты сайта отдаёт 200, свой `title`, один `h1`,
   `canonical`, хлебные крошки и JSON-LD без ошибок валидатора.
2. Заявка с формы видна в `crm_leads` с адресом страницы и UTM.
3. Цена «от» на посадочных посчитана тем же движком, что КП менеджера, а не
   вписана руками.
4. Через 8–12 недель после домена: страницы в индексе Вебмастера, первые заявки
   с поиска.

## Архитектура

- **Отдельный проект `sites/zerkala/`** в репозитории mglass-app — Next.js 16,
  статическая сборка, без базы и без секретов. Корневой `tsconfig`/`eslint`
  приложения его не трогают (исключены).
- **Почему не внутри приложения:** корневой `app/layout.tsx` приложения на каждом
  запросе ходит в Supabase Auth — страницы становятся динамическими, а middleware
  проверяет сессию на каждом заходе робота. Сайту под SEO нужна статика с CDN.
- **Почему не `mglass-web`:** он вне git, мультинаправленный (зеркала — один раздел
  из пяти), а конкуренты, которые берут выдачу, — тематические сайты про зеркала.
  Из него взято проверенное: логика формы заявки и UTM, схемы JSON-LD, фото работ.
- **Данные и цены живут в mglass-app.** Сайт получает их через публичные
  эндпоинты приложения (С2 — заявка, С3 — цена), поэтому ключ service-role в
  проект сайта не попадает.
- **Факты компании — в одном файле** `lib/site.ts`, у каждого значения указан
  источник. Пока владелец их не подтвердил, сайт закрыт от индексации
  (`SITE_INDEXABLE` не равен `1` → `robots: noindex` и `Disallow: /`).
- **Страницы — из данных.** Посадочная описывается записью в
  `content/landings.ts`: запрос, заголовки, тексты, вопросы, соседи по кластеру.
  Шаблон один, тексты у каждой свои.

### С3. Цены от кода и калькулятор — ЖДЁТ
Публичный `POST /api/public/mirror-price`: размеры и исполнение на входе, на выходе
только цена клиенту (себестоимость наружу не уходит), тот же путь, что
`app/api/calc/mirror/route.ts` + `financial_settings`. Сайт при сборке берёт цены
«от» для эталонных размеров и пересобирается раз в сутки (ISR).
**Доказательство:** цена на сайте для 800×600 с подсветкой совпадает с ценой в
«Расчёте» у менеджера.
Риск: цена на публичной странице = обещание клиенту. Проверка по `mglass-finance`.

## Грабли

- **Старый `mglass-web` выглядит готовым, но цифры в нём не наши.** Цены «от 4 900 ₽»,
  срок «5–10 дней», «производство в Мытищах» — ни у одного значения нет источника.
  Переносить тексты оттуда без сверки нельзя.
- **Корневой layout приложения делает все страницы динамическими** — поэтому сайт

## Потолок

- Этот маршрут строит сайт, а не позиции. Выход в топ по «зеркала на заказ москва»
