# Карточка объекта для сайтов (18.11.2026)

Одна готовая работа = одна карточка. Общая для трёх сайтов: зеркала (mglass-zerkala.ru),
душевые (mglass.pro), перегородки (стеклянные-перегородки.рф).
Источник — то, что присылает владелец: фото, размер, цена, адрес, чертёж.
Кадры из архива «Монтажи» — тот же формат, подпись бригадира на сайт не идёт никогда.

## Адрес → ЖК

1. Адрес из сообщения → Яндекс Карты: название ЖК, корпус не пишем.
2. Застройщик и год сдачи — наш.дом.рф (единый реестр новостроек) или сайт застройщика,
   два источника должны совпасть. Не совпало — пишем только ЖК и район.
3. Нет ЖК (вторичка, частный дом) — только район или посёлок.
4. В карточку и в репозиторий попадают ЖК, застройщик, район. Адрес остаётся только в сообщении.

Застройщика называем как факт («ЖК … от …»). Без «партнёр», «официально», без логотипа застройщика.

## Фото

- обрезка, горизонт, свет и цвет, лёгкая резкость, WebP;
- нейросетевое «улучшение» не применяем — оно меняет изделие;
- метаданные (координаты, телефон) удаляются;
- не публикуем: лица, людей в отражении, документы, номера квартир, деньги, вид из окна,
  по которому узнаётся квартира;
- alt и подпись — по видимому на кадре (правило `public-site-launch` §1).

## Где показываем

- страница «Работы» и отдельная страница объекта (`/raboty/<слаг>`);
- 1–2 карточки на коммерческой странице своей темы («зеркало с подсветкой» → объекты с подсветкой);
- позже, когда в одном ЖК наберётся 3+ объекта, — страница «Работы в ЖК …».

Что это даёт поиску: свои фото и цифры (против «малоценности» у Яндекса), местные слова
(район, ЖК), примеры цен. Запросы по конкретному ЖК редкие — это довесок, а не основной трафик.

## Разметка

Страница объекта — `Article` + `ImageObject`; цена — `Offer` только при цене владельца;
организация — `LocalBusiness` с адресом производства (Мытищи), не адресом объекта.
