# Сайт зеркал M-Glass (`sites/zerkala`)

Отдельный статический сайт под SEO: только зеркала на заказ. Маршрут, решения и
разбор конкурентов — `docs/site-zerkala/` в корне репозитория.

Это самостоятельный Next.js-проект со своим `package.json`. Корневые `tsconfig` и
`eslint` приложения его не проверяют, команды запускаются отсюда:

```bash
cd sites/zerkala
npm install
npm run dev          # http://localhost:3100
npm run build && npm start
npm run check:seo    # обход карты сайта на запущенном сервере
```

## Где что лежит

| Что | Где |
|---|---|
| Факты компании (телефон, год, юрлицо) с источником и флагом подтверждения | `lib/site.ts` |
| Тексты посадочных | `content/landings-*.ts` |
| Общие блоки: подсветка, материалы, рамы, этапы, цена | `content/knowledge.ts` |
| Фото работ и подписи | `content/photos.ts`, `assets/photos/` |
| Метаданные и JSON-LD | `lib/seo.ts` |

Новая посадочная — новая запись в `content/landings-*.ts`: страница, карта сайта,
меню и перелинковка появятся сами.

## Переменные окружения

| Переменная | Зачем |
|---|---|
| `NEXT_PUBLIC_SITE_URL` | Боевой домен: canonical, sitemap, разметка |
| `SITE_INDEXABLE=1` | Открыть сайт для поисковиков. Без неё — `noindex` и `Disallow: /` |
| `NEXT_PUBLIC_LEAD_ENDPOINT` | Куда форма шлёт заявку (этап С2, эндпоинт в mglass-app) |
| `NEXT_PUBLIC_YM_ID` | Счётчик Яндекс.Метрики |
| `NEXT_PUBLIC_YANDEX_VERIFICATION` | Код подтверждения Яндекс.Вебмастера |

С `SITE_INDEXABLE=1` сборка упадёт, пока в `lib/site.ts` есть факт с
`confirmed: false` или домен не боевой: открыть сайт с неподтверждёнными данными нельзя.

## Правила текстов

- Ни срока, ни гарантии, ни цены без подтверждения владельца: вместо цифры —
  «пришлите размеры, посчитаем».
- Цены «от» появятся из движка расчёта mglass-app (этап С3), не руками.
- Отзывы и рейтинг в разметку не кладём, пока они не собраны на самом сайте.
