# CEO Analytics Skill — Навык аналитики для CEO

## Назначение
Предоставлять владельцу полную картину бизнеса в реальном времени: KPI, выручка по менеджерам/продуктам, P&L, маржинальность, бонусы, прогнозы. Только читает данные — не меняет бизнес-логику.

## Модули и страницы
- `/admin/dashboard` — главный дашборд: выручка сегодня/месяц, менеджеры, активные заказы
- `/admin/pnl` — P&L отчёт по месяцам (orders: revenue, COGS, gross profit, net)
- `/admin/analytics-mglass` — аналитика по менеджерам с историческими данными
- `/admin/cfo` — финансовая модель: ТБ0, ТБ1, ДДС, сценарный анализ
- `/admin/owner` — Owner Center: стратегические цели, квартальный план
- `/admin/bonus-center` — бонусный центр: комиссионные тиры, расчёт бонусов
- `/admin/sales-center` — Sales Center: скрипты, follow-up задачи, обратная связь
- `/admin/b2b-development` — B2B Development: воронка, клиентская база
- `/b2b-analytics` — B2B аналитика по клиентам и сегментам
- `/ai-stats` — статистика Telegram-бота (запросы, популярные команды)
- `/amo-analysis` — воронка AMO CRM: этапы, конверсия, менеджеры

## API маршруты
- `GET /api/cbr-rate` — курс ЦБ (для P&L в валютных расчётах)
- `GET /api/amo/analyze` — AI-анализ воронки AMO
- `GET /api/amo/manager-stats` — статистика менеджеров AMO
- `GET /api/admin/owner-strategy` — стратегические цели владельца
- `POST /api/admin/owner-strategy` — обновить стратегические цели
- `POST /api/admin/sales-bonuses` — расчёт/сохранение бонусов менеджеров
- `GET /api/admin/sales-feedback` — обратная связь по продажам
- `GET /api/admin/sales-scripts` — скрипты продаж
- `GET /api/admin/sales-followups` — follow-up задачи
- `GET /api/cron/anomalies` — детекция аномалий в данных
- `GET /api/cron/agent-ceo` — CEO AI-агент (cron)
- `GET /api/cron/agent-revenue` — агент выручки (cron)

## Таблицы БД
| Таблица | Роль |
|---------|------|
| `calculations` | Выручка, маржа, продукты — основа всех отчётов |
| `orders` | Заказы: статус, оплата, gross_profit для P&L |
| `users` | Менеджеры: name для отчётов |
| `b2b_quotes` | B2B воронка: конверсия просчётов |
| `b2b_orders` | B2B заказы: выручка B2B-канала |
| `owner_strategy` | Стратегические цели и квартальный план |
| `agent_memory` | Память CEO AI-агента |
| `cfo_settings` | Настройки финансовой модели (ТБ0/ТБ1/ДДС) |

## Ключевые файлы
| Файл | Роль |
|------|------|
| `lib/commissionTiers.ts` | Тиры комиссионных: пороги выручки → % бонуса менеджеру |
| `lib/useOwnerStrategy.ts` | React hook: загрузка стратегии владельца для компонентов |

## Роли и доступ
- **ceo**: полный доступ ко всем аналитическим страницам
- **admin**: полный доступ
- **seo**: только `/b2b-analytics`, `/amo-analysis`, `/ai-stats`, маркетинг
- **manager**: только `/manager-dashboard` (свои данные)

## Входные данные
Период анализа, фильтры по менеджеру/продукту/статусу (параметры URL или форма).

## Выходные данные
KPI-дашборд, P&L-таблица, рейтинги менеджеров, бонусные расчёты, AI-рекомендации CEO-агента.

## Что уже реализовано
- Dashboard: выручка сегодня/месяц vs прошлый, активные/завершённые заказы, средняя маржа, долг клиентов
- Топ-менеджеры по выручке и количеству расчётов
- P&L помесячный из `orders`
- CEO AI-агент с cron и памятью
- Стратегия владельца (owner_strategy)
- Бонусный центр с комиссионными тирами (`lib/commissionTiers.ts`)
- CFO модуль: ТБ0, ТБ1, ДДС (3 налоговые системы), сценарный анализ, SVG-график

## Что нужно доработать
- P&L с реальной постатейной разбивкой расходов (сейчас упрощённый расчёт по %)
- Cash flow прогноз на 3–6 месяцев
- Сравнение план/факт по стратегическим целям
- Автоматические алерты при отклонении KPI от плана

## Риски
- Dashboard читает `calculations` напрямую без кеша — при объёме >10k строк замедлится
- P&L зависит от `NEXT_PUBLIC_CBR_KEY` для курса валют — при отсутствии ключа показывает без пересчёта
- CFO-настройки (`cfo_settings`) требуют SQL-миграции — до деплоя страница работает на дефолтах

## Тесты
- Integration: dashboard загружает данные за текущий месяц без ошибок
- Integration: P&L корректно группирует orders по месяцам
- Smoke: все CEO-страницы рендерятся без ошибок для роли `ceo`
- Smoke: `/admin/cfo` рендерится и показывает метрики ТБ0/ТБ1

## Связи с другими Skills
- **Order Management Skill** — данные заказов: revenue, gross_profit, статусы
- **Calculation Skill** — расчёты: маржа, выручка по продуктам
- **Integration Skill** — AMO-данные для анализа воронки
- **AI Control Center Skill** — данные выручки передаются в AI-анализ
