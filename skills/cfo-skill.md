# CFO Skill — Навык финансовой модели

## Назначение
Строить финансовую модель бизнеса изнутри: точки безубыточности (ТБ0/ТБ1), денежный поток (ДДС) по налоговым системам, сценарный анализ (пессимизм/база/оптимизм), раздел прибыли по фондам. Думает категориями: денежный поток, структура затрат, точки безубыточности.

## Модули и страницы
- `/admin/cfo` — страница Финдиректора (единственная страница этого Skill)

## API маршруты
- `POST /api/cfo-settings` — upsert настроек в `cfo_settings` (id=1, singleton)

## Таблицы БД
| Таблица | Роль |
|---------|------|
| `cfo_settings` | Singleton (id=1): entity_type, tax_system, fixed_costs (jsonb), profit_split (jsonb), avg_variable_pct, monthly_revenue_target |
| `calculations` | Исторические данные выручки для SVG-графика (last 12 months, status=approved) |

> ⚠️ `cfo_settings` требует SQL-миграции (выполнена 26.05.2026). До деплоя страница работает на дефолтах из кода.

## Ключевые файлы

## Роли и доступ
- **admin**: полный доступ, может редактировать настройки
- **ceo**: полный доступ, может редактировать настройки

## Входные данные (настройки)
- `entity_type`: ip | ooo
- `tax_system`: usn_6 | usn_15 | osno
- `fixed_costs`: { rent, payroll, marketing, other } (₽/месяц)
- `profit_split`: { owner_pct, education_pct, reserve_pct } (% от чистой прибыли)
- `avg_variable_pct`: средний % переменных расходов от выручки
- `monthly_revenue_target`: целевая выручка месяца

## Выходные данные
- **ТБ0** — выручка при которой бизнес в ноль без вывода прибыли
- **ТБ1** — выручка при которой покрыты расходы + наполняются все фонды
- **ДДС** — денежный поток с разбивкой: выручка, COGS, FC, налог, страховые взносы, НДС, чистая прибыль
- **Сценарный анализ** — 3 сценария × полный ДДС каждого
- **Раздел прибыли** — суммы в фонды собственника, обучения, резерва
- **SVG-график** — 12 месяцев выручки с линиями ТБ0 и ТБ1

## Формулы (ядро)

```
ТБ0 = FC / (1 − VC%)
ТБ1 = FC / ((1 − VC%) × (1 − split%))

ИП УСН 6%:
  rawTax = Revenue × 6%
  deduction = min(4125, rawTax × 50%)
  Tax = rawTax − deduction
  Net = Revenue − COGS − FC − 4125 − Tax

ИП УСН 15%:
  Base = max(Revenue − COGS − FC, 0)
  Tax = max(Base × 15%, Revenue × 1%)
  Net = Revenue − COGS − FC − 4125 − Tax

ООО ОСНО:
  vatOut = Revenue × 20/120
  vatIn  = COGS × 0.7 × 20/120
  profitBefore = (Revenue − vatOut) − (COGS − vatIn) − FC
  incomeTax = profitBefore × 20%
  Net = (profitBefore − incomeTax) × (1 − 0.13)
```

## Что нужно доработать (из PROMPT_CFO_MODULE.md)
1. **Прогноз на год** — таблица по месяцам на основе тренда последних 3 месяцев
2. **B2B/B2C mix** — доля каждого канала → итоговая налоговая нагрузка
3. **Детализация постоянных** — статьи расходов с историей изменений
4. **Интеграция с orders** — использовать данные orders (не только calculations) для более точной выручки
5. **Алерт при пересечении ТБ** — уведомление когда месяц пересёк ТБ0 или ТБ1

## Риски
- `cfo_settings` — singleton (id=1). При отсутствии таблицы страница работает на дефолтах без ошибок
- Выручка на графике берётся из `calculations` (status=approved) — не включает B2B orders
- Прогноз (ср. 3 мес.) исключает текущий месяц — при малом количестве данных может быть некорректным

## Тесты
- Smoke: `/admin/cfo` рендерится без ошибок даже при отсутствии cfo_settings таблицы
- Integration: POST `/api/cfo-settings` → upsert в БД → перезагрузка показывает новые значения
- Unit: `calcTB0(250000, 45)` → 454545
- Unit: `calcDds(1000000, 'usn_6', 45, 250000)` → корректный Net
