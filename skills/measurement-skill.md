# Measurement Skill — Навык замеров

## Назначение
Принимать заявки на замер от менеджеров, уведомлять команду, хранить данные замера с фотографиями. Мост между первым контактом клиента и созданием расчёта.

## Модули и страницы
- `/measurer` — форма замера для менеджера (данные клиента + фото)
- `/calendar` — календарь замеров и встреч

## API маршруты
- `POST /api/measurer` — создать заявку на замер (multipart: данные + фото-файлы)
- `GET/POST /api/appointments` — записи календаря (замеры, встречи)

## Таблицы БД
| Таблица | Роль |
|---------|------|
| `measurements` | Заявки: client_name, address, phone, product_type, dimensions, notes, photos (URL[]) |
| Supabase Storage `backups` | Физические файлы фотографий замеров |

## Ключевые файлы
| Файл | Роль |
|------|------|
| `lib/telegram.ts` | `notifyAdmins()` — уведомление admin в Telegram при новом замере |

## Роли и доступ
- **manager**: создаёт заявки на замер, видит свои записи в календаре
- **admin/ceo**: видит все замеры и календарь

## Входные данные
Имя клиента, адрес, телефон, тип продукта (mirror/loft/shower), размеры, заметки, фотографии (несколько файлов).

## Выходные данные
Запись в `measurements`, загруженные фото в Supabase Storage, Telegram-уведомление admin с деталями замера.

## Что уже реализовано
- Форма замера с валидацией полей и загрузкой нескольких фото
- Сохранение в `measurements`
- Telegram-уведомление admin через `notifyAdmins()`
- Календарь с записями (appointments)

## Что нужно доработать
- Связь замера с заказом (measurement_id → order_id): замер должен конвертироваться в расчёт и заказ
- Страница списка замеров для admin с фильтрами
- Интеграция с Google Календарём для sync встреч
- SMS/WhatsApp подтверждение замера клиенту

## Риски
- Фото загружаются в bucket `backups` без лимита — может расти неконтролируемо
- Нет подтверждения замера клиенту (только admin-уведомление)
- При сбое Telegram-уведомления замер сохраняется, но admin не узнает

## Тесты
- Integration: POST `/api/measurer` с файлами → запись в measurements + файлы в Storage + Telegram
- Smoke: форма замера открывается, поля валидируются, файлы принимаются
- Smoke: календарь отображает записи

## Связи с другими Skills
- **Order Management Skill** — замер должен конвертироваться в заказ (связь пока не реализована)
- **Integration Skill** — Telegram-уведомление через `lib/telegram.ts`
