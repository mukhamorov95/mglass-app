# Skill: Sales Monitor — Ежедневный контроль отдела продаж

## Назначение

Автоматический ежедневный отчёт по активности менеджеров из AmoCRM → Telegram.
Запускается в 18:00 МСК (пн–пт). Только GET-запросы — **никаких следов в карточках**.

---

## Менеджеры

Берутся из `AMOCRM_MANAGERS_IDS` (env). Владелец (`AMO_VLADISLAV_USER_ID`) исключается.
Текущие менеджеры: Яна, Алина, Александра, Семён.

---

Берём **только воронку "Продажи"**. Остальные воронки игнорируем.

## Метрики на менеджера (за день)

| Метрика | Источник AmoCRM |
|---|---|
| Активных сделок | Лиды `closed_at === null`, фильтр client-side по responsible_user_id |
| Зона 1 / 2 / 3 | Количество активных лидов по зонам |
| Лидов сегодня | Лиды `created_at >= todayStart` |
| Звонков | Notes `note_type=4` (исходящий) или `13` (входящий) за сегодня |
| Сообщений | Notes `note_type=10` (SMS) или `1` (текст) за сегодня |
| Перемещений | Events `type=lead_status_changed` за сегодня |

### Про звонки
В AmoCRM Analytics → Звонки → фильтр "Разговор" = состоявшиеся звонки.
API: `GET /leads/notes?filter[note_type]=4,13&filter[created_at][from]=...&limit=250`.

## Красные флаги (РОП-аналитика)

| Флаг | Условие |
|---|---|
| 🔴 Ноль активности | messagesSent + callsMade === 0 |
| 🔴 Нет перемещений | cardsMoved === 0 && activeLeads > 3 |
| 🔴 Зона 1 зависшие | daysStale ≥ 2 дня |
| 🔴 Счёт без оплаты | Зона 2, этап содержит "счёт/ждём", daysStale ≥ 5 дней |
| 🟠 Зона 2 зависшие | daysStale ≥ 3 дня |
| 🟡 Зона 3 зависшие | daysStale ≥ 3 дня |

## Технический стек

| Файл | Назначение |
|---|---|
| `lib/amocrm.ts` | Клиент AmoCRM API v4 (read-only, token из env, пагинация) |
| `lib/salesMonitor.ts` | Сбор метрик + `buildReport()` для Telegram |
| `app/api/cron/sales-monitor/route.ts` | GET-endpoint, auth: `Bearer CRON_SECRET` |
| `vercel.json` | Cron `"0 15 * * 1-5"` = 18:00 МСК, пн–пт |

### Принципы READ-ONLY
```
✅ GET /api/v4/leads, /events, /users, /pipelines, /leads/notes
❌ POST/PATCH к сделкам, задачам, примечаниям — запрещено
```
